## Frequently asked questions

### Why aren't my steps showing?

footstepeR reads steps from Apple Health. Open Settings → Privacy → Health →
footstepeR and make sure all toggles are enabled. If you are using a device
without Health access (rare), the app falls back to Core Motion, which still
needs Settings → Privacy → Motion & Fitness → footstepeR to be enabled.

### How do I cancel my subscription?

iOS Settings → Apple ID → Subscriptions → footstepeR → Cancel. Refunds are
handled by Apple.

### How do I delete my account?

In the app: Settings → Account → Delete Account. This permanently removes your
data from our cloud database and from this device.

### The AI Coach is silent. What happened?

Make sure microphone and speech recognition are allowed:
Settings → Privacy → Microphone → footstepeR and
Settings → Privacy → Speech Recognition → footstepeR.
The Coach also requires an internet connection.

### My GPS route is jagged.

Run on a device that has been outdoors for a minute so it can lock onto enough
satellites. Indoors, GPS is unreliable. Make sure
Settings → Privacy → Location Services → footstepeR is set to "While Using" or
"Always".
